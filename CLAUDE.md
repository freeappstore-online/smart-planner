# smart-planner

Smart Planner — a small, local-first React + Vite planner app (web/).

Quick start (repo root):

- Prerequisites: Node >= 22, pnpm
- Install: `pnpm install`
- Dev: `pnpm dev` (starts the `@smart-planner/web` Vite dev server)
- Build: `pnpm build`
- Preview: `pnpm preview`

Layout:

- `web/` — React + TypeScript + Vite single-page app (main UI and source)
