# Smart Planner Skills

## Repo

- App name: Smart Planner
- Subdomain: `smart-planner.freeappstore.online`
- Local dev: `pnpm install && pnpm dev`
- Build: `pnpm build`
- Compliance: `fas check`

- Keep the public manifest and app branding aligned with Smart Planner.
- Preserve the existing PWA setup and localStorage state model.
